# 경찰시험 통합 학습관리표

## GitHub Pages 게시
1. GitHub에서 새 저장소를 만듭니다. 저장소 이름은 `police-study`를 권장합니다.
2. 저장소 공개 범위는 **Public**으로 설정합니다.
3. 이 ZIP을 압축 해제한 뒤 `index.html`, `manifest.webmanifest`, `sw.js`, `icons` 폴더를 저장소 최상위(root)에 올립니다.
4. 저장소의 **Settings → Pages**로 이동합니다.
5. **Deploy from a branch**를 선택하고 Branch는 `main`, Folder는 `/(root)`로 설정한 뒤 Save를 누릅니다.
6. 배포가 완료되면 `https://깃허브아이디.github.io/police-study/` 주소로 접속합니다.

## iPhone 홈 화면에 설치
1. iPhone의 Safari에서 위 GitHub Pages 주소를 엽니다.
2. 공유 버튼을 누르고 **홈 화면에 추가**를 선택합니다.
3. 가능하면 **웹 앱으로 열기**를 켜고 추가합니다.

## 체크 기능
- 강의별 체크: 개별 강의 완료 상태를 저장합니다.
- 날짜별 `하루 완료`: 해당 날짜의 학습을 마쳤을 때 체크합니다.
- 두 체크는 별도로 저장되며, 날짜별 완료 수가 상단에 표시됩니다.
- 체크 기록은 해당 기기의 웹앱 저장 공간에 저장됩니다. 다른 기기와 자동 동기화되지는 않습니다.
- 첫 온라인 접속 후에는 서비스 워커가 앱 파일을 저장해 오프라인 실행을 지원합니다.

## 업데이트
수정된 파일을 같은 저장소 최상위에 덮어씁니다. 서비스 워커 파일이 바뀌는 업데이트에서는 `sw.js`의 `CACHE_NAME` 버전을 올려야 이전 캐시가 교체됩니다.
